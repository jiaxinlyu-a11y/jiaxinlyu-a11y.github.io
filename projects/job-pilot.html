Case study · Self-built tool

JobPilot

I built JobPilot to fix the problems I kept running into while job hunting. It is a web app for one user: every job I save, where it stands, and what each interview taught me, in one place.

01Why I built it

A job search starts tidy and gets messy fast. Postings sit in bookmarks, notes and email threads. After a few weeks it is hard to say which jobs I applied to, which are waiting for an answer, and when anything happened. Interview lessons are the first thing to go: a week later I could not say what I was asked or what I should do better next time. Each of these is small, but together they cost time and let good lessons slip away.

02What I built for each problem

I designed the app around those problems, one feature for each. A job moves through six statuses: Saved, Planned, Applied, Interview, Offer and Rejected. Each status is a dated milestone, and I can backdate one if I forgot to record it. Interview rounds are kept apart from status, so a job can have several rounds without the status getting messy.

The dashboard shows the same data two ways: a board grouped by current status, with a badge for the latest interview round, and a timeline with one row per job, coloured status bars and a marker for every round.

03Did it solve the problem?

Yes. Judging by what the app does, every problem in section 01 now has a direct answer. A new job takes one entry. Its history is a set of dated milestones, so “when did I apply?” is a lookup instead of a guess. The board and the timeline show the whole search without opening each job. Every interview round has its reflection form attached, so what I was asked and what to improve stay with the job. The profile holds my details and files, so I do not retype them for each application.

It is built with Next.js and TypeScript on Supabase: login, a PostgreSQL database with row-level security so only the owner can read the data, and private file storage. The current status comes from the latest dated milestone and is kept in sync by database triggers.
