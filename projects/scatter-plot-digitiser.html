Scatter Plot Digitiser

I built this small Python tool to read data back from a published scatter plot. It finds the points, converts them to real values using the axes, and checks its own accuracy against known values.

01Why I built it

For my KETO-CTA re-analysis, one variable was not in the released data. It only existed as a published scatter plot. To use it, I needed to turn the picture back into numbers, and to know how far to trust them.

02How it works

You upload the plot image, crop it to the plotting area and click four tick marks, entering their real values. The tool detects black circular points and converts their positions into data values. Missed points can be added and false detections deleted by hand.

03How accurate is it?

The tool is built to be checked. When known values are available, it matches each digitised point to one and reports the error, and a diagnostic plot lets you confirm the matches by eye. Most points are found automatically. Where points overlap, I add the rest by hand: 6 on the baseline plot and 12 on the change plot. Each one is flagged as manual in the export.
